Pattern

Data tables and lists

Wayfold shows collections as lists, not tables: a grid of vehicle cards for search, garages and dealer inventory, a grid of cards for providers and products, and a detail list for a vehicle's specifications. A result count, filters above, and one link per item hold them together.

Overview

No Wayfold mock uses a data table. Vehicles are chosen by looking, so the photo and price lead; providers and products are chosen by trust, so the name and "Recommended by N members" lead. Every collection is a <ul> of items, each with exactly one link (the title), so a screen reader hears "list, 4 items" and the tab order is one stop per item.

Components: Vehicle card, Card, Detail list, Filters, Badge, Skeleton.

Structure

Page head, filters as a role="search" form, a live result count, then the list. The card's title link is the only link; price leads; meta lines carry kilometres, municipality, price rating and seller.

Responsive behaviour

  • Grids are one column on phones and add columns as space allows; cards never shrink below a readable width and never scroll sideways.
  • Filters stack above the list on phones and sit in one row from MD.
  • Detail lists put the term above the value on phones and beside it from SM.
  • Images keep a 4:3 ratio with width and height set, so the grid does not shift while photos load.

Accessibility

  • Collections are <ul>; specifications are <dl>. One link per card, on the title; the price is text, not a link.
  • Photo alt names the vehicle and the view: "2021 Honda Civic Sport, front view".
  • The result count is a polite live region so filtering is announced (WCAG 4.1.3).
  • Price rating is text ("Good price"), never colour alone (WCAG 1.4.1).

Content

  • Title: year, make, model, trim: "2019 Toyota RAV4 XLE".
  • Prices in CAD with a comma and no cents: "$24,995". Distances as "48,200 km".
  • Meta order: kilometres · municipality · price rating, then seller ("Private seller · Priya Nair" or the dealer name).
  • Count names the noun and the sort: "248 vehicles · Newest first".

Do and don't

Sources

Mocks: vehicles, providers, products, dealer-inventory, vehicle-detail, member.

Drift

  • vehicles, providers, products no-results: the filters form is removed and the copy says "category" on vehicles. Resolution: keep filters, echo the query, say "Try another make, seller type or municipality".
  • vehicles/empty: "New activity will appear here as people join the community" with "Browse again". Resolution: "No vehicles listed yet" and a "Sell your car" action.
  • loading states: one card of text skeletons instead of card-shaped placeholders. Resolution: skeleton cards matching the grid.
  • dealer-inventory/default: "Delete selected vehicle" link with no selection and no per-item Edit. Resolution: Edit and Delete buttons on each listing.
  • No tables in any mock; .table--stack in components.css is unused. Resolution: lists only until a mock needs a table.
