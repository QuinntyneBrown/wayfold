Avatar

The avatar shows a member's initials in a circle beside their name on their profile and in the site header.

WCAG 2.2 AAStatus: stable.avatar.avatar-btn

Overview

Use an avatar next to a member's visible name: the profile head (.member-head, L2-010) and the header account button (.avatar-btn) that opens the account menu. The mocks show initials only; there is no photo avatar.

Anatomy

  1. Circle--target-comfortable square, --radius-full, --color-bg-subtle.
  2. InitialsTwo letters in --text-label.

Sizes

One size: --target-comfortable (48px), which also makes the header button a comfortable target.

States

  • Default (decorative): no states.
  • As a button (.avatar-btn): hover and the focus ring belong to the link around it.
PN
Forced focus.
HTML
<a class="avatar-btn" href="../../mocks/dialogs/account-menu/default.html" data-state="focus" aria-label="Account menu for Priya Nair"><span class="avatar" aria-hidden="true">PN</span></a>

Responsive behaviour

  • Size does not change.
  • In .site-nav the avatar button is hidden below 48rem.

Theming

--color-bg-subtle behind --color-fg-default initials in both themes.

Accessibility

Beside a visible name the avatar is aria-hidden="true"; the name is read once. As the header button, the link carries aria-label="Account menu for Priya Nair".

Contrast

Initials on avatar

Content

  • First letter of the first and last name, uppercase: "PN".
  • One letter if the member has one name.
