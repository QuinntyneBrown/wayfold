Vehicle card

The vehicle card shows one car for sale in a grid: photo, price, year-make-model, mileage and area, and who is selling it. Private and dealer listings use the same card.

Overview

Use the vehicle card wherever listings appear in a list: home "Cars for sale", vehicle search, a member's "For sale" tab and dealer inventory (L2-008, L2-034). It always sits in ul.vehicle-grid. The detail page uses gallery and detail list instead.

Anatomy

  1. Photo.vehicle-card__media, 4:3, cover, with --color-bg-photo behind it while it loads. Alt names year, make, model and view.
  2. Price.vehicle-card__price in --text-h3; Canadian dollars, no cents.
  3. Title link.vehicle-card__title: the only link, to the vehicle page.
  4. Meta lines.list__meta: mileage and area, then seller.

Sizes

One size. .vehicle-grid tracks are at least 18rem; the photo keeps 4:3 at any width.

States

  • Default: as above.
  • Link hover and focus: the title link takes the link hover colour and the focus ring.
  • Loading: the grid is replaced by skeleton cards; see Skeleton.
  • Empty / no results: no cards; an empty state explains why (pages/vehicles/no-results).

Responsive behaviour

  • repeat(auto-fit, minmax(min(100%, 18rem), 1fr)): one column on phones, two to four on wider screens.
  • The photo scales; it never crops the price or title.
  • Meta lines wrap rather than truncate.

Theming

Same surface and edge as card. The photo placeholder is --color-bg-photo in both themes.

Accessibility

Role and pattern

Each card is a list item in ul.vehicle-grid, so a screen reader announces "list, 2 items". The title is the one link; the photo is not wrapped in a second link, so there is one tab stop per car.

Keyboard

KeyAction
TabMoves to the next card's title link.
EnterOpens the vehicle page.

Contrast

Images

Alt text names the car and the view ("2019 Toyota RAV4 XLE, front view"). width and height are set so the grid does not shift as photos load.

Content

  • Price first, formatted $24,995.
  • Title is year, make, model, trim: "2021 Honda Civic Sport".
  • Meta line 1: mileage in km and GTA municipality. Line 2: "Private seller · Name" or the dealer name.
