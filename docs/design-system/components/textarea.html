Textarea

Overview

A multi-line input for anything written in sentences: a vehicle description, a feed post, a comment, a message to a seller, a question for financing experts, a recommendation, notes on a garage car. It uses the same .field wrapper, help and error as the text field.

Anatomy

  1. LabelVisible <label for>.
  2. Textarea.textarea, rows="4", vertical resize only.
  3. Help or errorTied with aria-describedby.

Variants

One variant. Every textarea in the mocks is four rows with vertical resize; length limits are expressed in help or error text.

Sizes

One size: rows="4" by default, resizable vertically by the member.

States

Write 10 to 500 characters
Filled, focus, invalid (recommend dialog) and disabled.

Both themes

While a dialog sends, the textarea stays as typed; on failure the text is kept so the member does not retype it (dialogs/*/failed).

Responsive behaviour

Full width of its column at every size. Resize is vertical only, so a member cannot drag it wider than a phone screen.

Theming

Shares --field-bg, --field-border and --field-fg with the text field; nothing textarea-specific.

Accessibility

Visible label, aria-describedby for help and error, aria-invalid when invalid, as for the text field. Character limits are stated up front in help text, not only in the error.

KeyAction
TabMoves into and out of the textarea; Tab never inserts a tab character.
EnterInserts a new line; it does not submit.

Contrast

Field border on surface
Label on surface
Help text on surface
Error text on surface
Invalid border on surface

Content

  • Labels name what to write: "Description", "Message", "Your question", "Why you recommend them", "Write a post".
  • Prefill a helpful start only where the mock does: the contact dialog's "Hi, is the … still available?"
  • Errors give the rule: "Write 10 to 500 characters", "Write your question".

Code

<div class="field">
  <label class="field__label" for="question">Your question</label>
  <textarea class="textarea" id="question" name="question" rows="4"
            aria-invalid="true" aria-describedby="question-error"></textarea>
  <span class="field__error" id="question-error">Write your question</span>
</div>
