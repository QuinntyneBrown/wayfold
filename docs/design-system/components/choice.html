Checkbox and radio

A checkbox or radio with its label text in one clickable row. Its main job in Wayfold is the member's choice to show their home church.

Overview

A checkbox or radio with its label text, wrapped in one <label class="choice"> so the whole row is the target. Wayfold uses a checkbox for a single on/off preference: "Show my home church to signed-in members" (L2-022). Radios are available for two to five mutually exclusive options that should all stay visible; no current mock uses one.

Anatomy

  1. ControlNative input restyled: 20px box (--icon-size-md), --radius-xs for a checkbox, round for a radio; filled with --color-accent when checked.
  2. Label text.choice__text, body size.
  3. Description (optional)A <small> inside .choice__text, muted; part of the accessible name, so keep it short.

Variants

Checkbox: a single preference, from pages/settings/default.
HTML
<label class="choice"><input type="checkbox" name="show-church" checked><span class="choice__text">Show my home church to signed-in members</span></label>
Condition
Radio group in a <fieldset> with a <legend>. Shown with the vehicle editor's condition options; the editor currently uses a select, which is also correct.
HTML
<fieldset class="stack" style="border: 0; padding: 0; margin: 0;"><legend class="field__label">Condition</legend><label class="choice"><input type="radio" name="cond" checked><span class="choice__text">Used</span></label><label class="choice"><input type="radio" name="cond"><span class="choice__text">New</span></label></fieldset>

Sizes

One size: 20px control; the row is at least 24px tall and 44px below 48rem.

Responsive behaviour

The label text wraps beside the control; the control stays top-aligned with the first line. Below 48rem each row is at least 44px tall.

Theming

Unchecked uses --color-border-strong on --color-bg-surface; checked fills with --color-accent and draws the tick or dot in --color-fg-on-accent. Both themes come from those semantic tokens.

Accessibility

Labelling

The wrapping <label> names the input and makes the whole row clickable. Related help outside the label is tied with aria-describedby. A radio group sits in a <fieldset> with a <legend>.

KeyAction
TabMoves to the checkbox, or into a radio group (to the checked radio).
SpaceToggles the checkbox; checks the focused radio.
Arrow keysMove and check within a radio group.

Contrast

Content

  • Label a checkbox with what happens when it is on: "Show my home church to signed-in members", not "Church visibility".
  • No negatives ("Don't show…"): checked always means yes.
  • Radio options are short nouns: "Used", "New".
