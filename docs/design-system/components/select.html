Select

A native select for one choice from a fixed list: seller type, make, GTA municipality, provider or product category.

Overview

A native <select> for one choice from a fixed list: seller type, make, GTA municipality, provider category, product category, vehicle condition. Use it in filters and forms. For two or three options that should all be visible, use radio buttons.

Anatomy

  1. LabelVisible <label for>.
  2. ValueThe selected option. In filters the first option is the "no filter" choice: "All of the GTA", "Any make", "All sellers".
  3. ChevronDrawn in currentColor with two gradients; native arrow removed with appearance: none.

Variants

One variant: the native single select. Wayfold has no multi-select, combobox or custom listbox.

Sizes

One size: 44px (--control-height-md).

States

Choose a category
Default, hover, focus, invalid and disabled.

Both themes

Responsive behaviour

Full width of its column. On phones the operating system's own picker opens, which is why Wayfold keeps the native element.

Theming

Shares --field-bg, --field-border and --field-fg with the text field. The chevron uses currentColor, so it follows --field-fg in both themes and greys out when disabled.

Accessibility

Native <select> with a visible label; the browser supplies the combobox role and option announcements.

KeyAction
TabMoves to and from the select.
Up / DownChanges the option (or opens the list, depending on platform).
Alt+Down, SpaceOpens the list.
Type a letterJumps to the first matching option.

A select never submits or navigates on change; the member presses "Search" (WCAG 3.2.2).

Content

  • In filters, the first option means "no filter" and says so in words: "All of the GTA", "Any make", "All sellers", "All".
  • In forms, a required select with no sensible default starts on "Choose a …" with an empty value.
  • Options are plural nouns for groups ("Dealers", "Body shops") and proper names for places ("Etobicoke", "Scarborough").

Code

<div class="field">
  <label class="field__label" for="area">GTA municipality</label>
  <select class="select" id="area" name="area">
    <option value="">All of the GTA</option>
    <option>Toronto</option>
    <option>Etobicoke</option>
  </select>
</div>

Drift found during extraction:

  • settings labels the municipality list "GTA area"; every other mock says "GTA municipality". Resolution: "GTA municipality".
  • The vehicles filters have no price range or model filter although L2-008 asks for keyword, price range, make, model and seller type. Flagged for the vehicles mock; not added here.
  • Filter selects have no value on the "no filter" option, so "All of the GTA" would be sent as a value. Resolution: value="" on the first option.
