Filters

The search form above every Wayfold list: a search box, a few selects and a Search button that reflow from one row on a desktop to one column on a phone.

Overview

A search form above a list: a search input, one to three selects and a primary "Search" button in an auto-fitting grid. It sits on Vehicles (L2-008), Providers (L2-031) and Products (L2-029). Results update when the member presses Search; the result count below is a role="status" line ("248 vehicles · Newest first").

Anatomy

  1. Search fieldtype="search" text field, first.
  2. Filter selectsEach a full .field with a visible label.
  3. Search buttonPrimary, last, fills its grid cell (.filters .btn).

Sizes

One size. Columns are at least 12rem and share the row equally.

States

  • Default: every filter on its "no filter" option; count line shows the total.
  • Filtered: chosen values stay in the controls after the page reloads (they come from the URL), so the member sees what produced the list.
  • Loading: the form stays usable; the list below shows skeletons (pages/vehicles/loading).
  • No results: the list is replaced by an empty state with "Clear filters" (pages/vehicles/no-results, L2-008.4).
  • Error: an alert with "Try again" replaces the list; the filters keep their values (pages/vehicles/error).

Both themes

Responsive behaviour

  • The grid is repeat(auto-fit, minmax(min(100%, 12rem), 1fr)): five columns on a wide screen, two or three on a tablet, one on a phone. Nothing scrolls sideways (L2-015.1).
  • Fields align to the bottom (align-items: end) so the button lines up with the inputs when labels wrap.
  • On a phone the Search button takes a full-width row of its own at the end.

Theming

Filters add no colour of their own; the fields and button carry their themes.

Accessibility

The form has role="search" (a search landmark) and, when a page has more than one, an aria-label. Every control has a visible label. Changing a select does nothing until Search is pressed (WCAG 3.2.2). The result count is a role="status" line so the new total is announced after the page loads.

KeyAction
TabMoves through search, selects and Search in order.
Enter in the search fieldSubmits the form.

Content

  • Label the search box with what it searches: "Search vehicles", "Search providers", "Search products". A bare "Search" (providers, products) repeats the button.
  • "No filter" options say what they cover: "All of the GTA", "Any make", "All sellers".
  • The button is "Search", always.
  • The count line: number, noun, middle dot, sort: "248 vehicles · Newest first".
