Section link

Full-width rows that list where you can go: the items of the phone site menu. Each row is a whole link, 72px tall, separated by hairlines.

WCAG 2.2 AAStatus: stable.section-list.section-link

Overview

Use section links where a short list of destinations needs big, easy targets: the site menu on phones. Each row is one <a>; there is no secondary text, icon or count in Wayfold today. Use site-nav links for the inline header, and a button for anything that acts rather than navigates.

Anatomy

  1. List.section-list: no bullets, a hairline on top.
  2. Row.section-link: flex row, at least 72px tall, hairline below, label in body text.

Sizes

One size: a 72px minimum row so each target is comfortably larger than 44px on a phone.

  • Hover tints the row with --color-bg-surface-sunken.
  • Focus draws the ring inset so it is not clipped by the sheet's scroll area.
  • Current shows a 3px accent bar on the start edge and aria-current="page".

Responsive behaviour

  • Rows fill their container; the label wraps rather than truncating.
  • Used below 48rem, inside the site menu; from 48rem the same destinations are inline in the header.

Theming

Hairlines use --color-border-default, hover --color-bg-surface-sunken, the current bar --color-accent; all follow the theme.

Accessibility

Role and pattern

A <ul> of links inside a labelled <nav>, so a screen reader hears "list, 8 items". No ARIA menu roles: these are links.

Keyboard

Contrast

Current is announced by aria-current, not only by the accent bar.

Content

  • Same names as the header: Feed, Vehicles, Providers, Products, Sell your car.
  • Account items start with "Your": Your profile, Your garage.
  • One destination per row; never two rows to the same page.

Drift found:

  • "Your profile" and "Your garage" both link to member/own. Resolution: one row until the garage has its own route.
  • "Sign out" is a link to home/default. Resolution: a ghost button below the list that posts the sign-out.
  • No row is ever marked current. Resolution: mark the section the menu was opened from.
