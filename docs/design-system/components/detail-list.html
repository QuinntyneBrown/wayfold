Detail list

The detail list shows a vehicle's specifications as label and value pairs: mileage, condition, location, features.

Overview

Use a detail list for facts about one thing that a buyer scans and compares: the "Vehicle details" card on a vehicle page (L2-035). Use a paragraph for prose description and a table when comparing several things.

Anatomy

  1. Termdt in --color-fg-muted, sized to the longest label (max-content).
  2. Valuedd in default text, taking the rest of the row.
  3. Row wrapperdiv with display: contents so each pair is one grid row.

Variants

One variant: two-column label and value.

Sizes

Body text; row gap --space-2, column gap --space-4.

States

  • Default: every row has a value.
  • Missing value: omit the row rather than show a dash.

HTML
<section class="card stack"><h2>Vehicle details</h2><dl class="detail-list"><div><dt>Mileage</dt><dd>48,200 km</dd></div><div><dt>Condition</dt><dd>Used · well maintained</dd></div><div><dt>Location</dt><dd>Scarborough</dd></div><div><dt>Features</dt><dd>Automatic, heated seats, backup camera</dd></div></dl></section>

Responsive behaviour

  • The label column stays max-content; long values such as features wrap in the value column.
  • At 320px the longest label ("Condition") leaves at least 12rem for the value.

Theming

Labels use --color-fg-muted, values --color-fg-default; both meet 4.5:1 on the card in both themes.

Accessibility

Native <dl>, <dt>, <dd>; wrapping each pair in a <div> is valid HTML and screen readers announce the pairs. Not focusable.

Content

  • Labels are nouns in sentence case: "Mileage", "Condition".
  • Values carry units: "48,200 km".
  • Separate short qualifiers with a middle dot: "Used · well maintained".
