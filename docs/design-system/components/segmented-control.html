Segmented control

A row of links between sections or categories of one page, with the current one marked: the member profile's Garage, For sale, Recommendations and Posts, and the provider categories.

Overview

A row of links that moves between sections of one thing, with the current one marked by aria-current="page". Wayfold has two forms and both are navigation, not form controls:

  • Segmented (nav.segmented): the member profile sections Garage, For sale, Recommendations and Posts. Each segment is its own URL.
  • Category nav (nav.category-nav): quick category links under the provider directory filters: All, Dealers, Mechanics, Body shops and the rest.

To narrow a list with several criteria at once, use filters. To pick a value inside a form, use a select or radio buttons.

Anatomy

  1. Container<nav> with an aria-label naming the set ("Profile sections", "Provider categories"); wraps, 8px gaps.
  2. Current segmentaria-current="page": accent text and edge, semibold.
  3. SegmentA link with a 1px --color-border-default edge, --radius-md, at least 44px tall.

Sizes

One size. Each segment is at least 44px tall (--target-comfortable) at every width.

States

DefaultHoverFocusCurrent
Default (muted text), hover (default text, strong edge), focus (shared ring), current (accent text and edge, semibold).

There is no disabled segment: a section with nothing in it still opens and shows its empty state ("No cars in the garage yet").

Responsive behaviour

  • Segments wrap onto further rows; they never scroll sideways (L2-015.1). At 360px the four profile segments take two rows.
  • The ten provider categories wrap to three or four rows on a phone; the category select in the filters above gives the same choice in one control.

Theming

Segments read --color-fg-muted, --color-border-default and, when current, --color-fg-accent and --color-accent. Both themes come from the semantic layer; there are no component tokens.

Accessibility

Role and pattern

A <nav> landmark with a distinct aria-label and plain links. Not a tablist: each segment loads its own URL, so links with aria-current="page" are the honest pattern.

Keyboard

KeyAction
Tab / Shift+TabMoves through the segments one at a time.

Current

The current segment is marked three ways: aria-current="page" (announced as "current page"), accent colour and semibold weight, so it does not rely on colour alone (WCAG 1.4.1).

Content

  • Nouns in sentence case, one or two words: "Garage", "For sale", "Body shops".
  • The first category is "All", never "Everything" or "Show all".
  • Name the <nav> for what it holds: "Profile sections", "Provider categories".

Drift found during extraction:

  • components.css defines .segmented twice: an underline-style rule set (muted text, accent current) and a later bordered-chip rule shared with .category-nav that sets current to font-weight: 700. The bordered version wins in every mock; the system keeps it and adds the accent edge for current, via --font-weight-semibold.
  • .category-nav in providers/default marks no link as current. Resolution: aria-current="page" on the active category ("All" by default).
  • Category links inherit the global underlined link style. Resolution: no underline inside .category-nav and .segmented; the chip edge marks them as links.
