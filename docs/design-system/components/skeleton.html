Skeleton

A skeleton is grey placeholder lines that hold a card's shape while its content loads.

WCAG 2.2 AAStatus: stable.skeleton.skeleton--text.skeleton--rect
  • Overview
  • Anatomy

Overview

Use skeleton lines in every page's loading state (13 mocks). They sit in an aria-hidden card; a visible <p role="status">Loading…</p> tells assistive tech, and main has aria-busy="true".

Anatomy

  1. Cardaria-hidden card.
  2. Lines.skeleton--text at varied widths.

Variants

Text lines.
HTML
<div class="card stack" aria-hidden="true"><span class="skeleton skeleton--text" style="width: 65%;"></span><span class="skeleton skeleton--text" style="width: 95%;"></span><span class="skeleton skeleton--text" style="width: 80%;"></span><span class="skeleton skeleton--text" style="width: 45%;"></span></div>
Rect, for a photo slot.
HTML
<div class="card" aria-hidden="true"><span class="skeleton skeleton--rect" style="aspect-ratio: 4 / 3;"></span></div>

Sizes

Text lines are 0.9em tall; rectangles take the size of what they replace.

States

Loading…

Loading state from pages/home/loading.
HTML
<div class="stack"><div class="card stack" aria-hidden="true"><span class="skeleton skeleton--text" style="width: 65%;"></span><span class="skeleton skeleton--text" style="width: 95%;"></span><span class="skeleton skeleton--text" style="width: 80%;"></span><span class="skeleton skeleton--text" style="width: 45%;"></span></div><p role="status">Loading…</p></div>

Responsive behaviour

  • Widths are percentages, so lines scale with the card.

Theming

Gradient from --color-bg-subtle to --color-bg-subtle-hover.

Both themes

Accessibility

Skeletons are aria-hidden; the status line is the accessible message. The shimmer stops under prefers-reduced-motion.

Content

  • Pair with "Loading…" status text.
  • Match the rough shape of what loads.
