Gallery

The gallery shows a vehicle's main photo at the top of its detail page.

WCAG 2.2 AAStatus: stable.gallery__main

Overview

Use .gallery__main once per vehicle page, first in the main column, before "Vehicle details" (L2-035). Today the mocks show one photo; there are no thumbnails, carousel or zoom, and the design system does not add them.

Anatomy

  1. Photo4:3, object-fit: cover, full column width.
  2. Corners--radius-lg, matching the cards beside it.

Variants

One variant: the main photo. Private and dealer listings use the same element.

Sizes

One size: 100% of the main column in .detail-layout, height from the 4:3 ratio.

States

  • Default: photo shown.
  • Loading: the page shows skeleton lines; the reserved 4:3 box keeps layout stable.
  • Sold: the photo stays; the sold card says the car is gone.
From pages/vehicle-detail/private.
HTML
<img class="gallery__main" src="../../mocks/assets/img/vehicle-2.svg" alt="2019 Toyota RAV4 XLE, front view" width="640" height="480" style="max-width: 22rem;">

Responsive behaviour

  • From 48rem the photo fills the wider (2fr) column; below it spans the screen inside the page margin.
  • Intrinsic width/height reserve space so nothing shifts as it loads.

Theming

Nothing to theme: the photo carries no token colour. It keeps its corners in both themes.

Accessibility

An <img> with alt that names the car and view ("2021 Honda Civic Sport, front view"). It is not focusable and not a link. The page h1 already names the car, so the alt adds the view, not marketing copy.

Content

  • Alt: year, make, model, trim, then the view.
  • Lead with an exterior three-quarter or front view.
