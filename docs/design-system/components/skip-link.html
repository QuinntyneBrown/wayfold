Skip link

The first thing a keyboard user reaches on every Wayfold page. It stays out of sight until focused, then appears over the site header and jumps straight to the page's <main>.

Overview

Every Wayfold page and every mock starts with <a class="skip-link" href="#main">Skip to content</a>, before the site header. The header carries up to seven targets (wordmark, four section links, "Sell your car", the avatar), so without the skip link a keyboard user tabs through all of them on every vehicle, provider and profile page (WCAG 2.4.1 Bypass blocks, L2-016.2).

The target is <main id="main" tabindex="-1">: the tabindex lets browsers move focus, not just scroll, so the next Tab lands on the first control in the page (the vehicle search filters, the feed composer, the sign-in email field).

Anatomy

  1. Label"Skip to content": the accessible name, the same on every page.
  2. ContainerRaised surface (--color-bg-surface-raised), --radius-md, --shadow-3, at least 44px tall (--target-comfortable).
  3. PositionAbsolutely placed 16px from the top and start edge while focused; parked above the viewport otherwise. Sits above the header on --z-tooltip.

Variants

There is one skip link per page and it always targets #main. Wayfold pages have no second repeated block (no side navigation) that would need another.

Sizes

One size. Its height is --target-comfortable (44px) at every width, and it never grows wider than the screen less 32px, so a longer translated label wraps rather than overflowing at 320px.

Hidden (default) and focused. Focus is forced here with data-state="focus"; real pages use :focus-visible.
  • Hidden: placed above the viewport, still in the tab order and the accessibility tree. It is never display: none.
  • Focused: slides to 16px from the top over --duration-fast, with the shared focus ring.
  • Activated: focus moves to <main>, which shows no ring because it is a landmark, not a control. The skip link hides again.
  • No hover, active or disabled states: it is visible only while focused.

Responsive behaviour

  • The same at every width: start-aligned, 16px from the edges.
  • max-width: calc(100vw - 2 * var(--space-4)) keeps it inside a 320px screen.
  • It sits over the header, so it covers the wordmark briefly while focused; nothing moves under it.
  • Hidden in print with the site header.

Theming

It uses the raised surface and default text, so it follows the theme with no overrides. In dark it is a lifted dark panel with light text; the shadow is weaker, so the focus ring carries the edge.

Accessibility

Role and pattern

A plain in-page link (WCAG 2.4.1). It is the first element in <body>, before the header, in every page and in the inert page behind a dialog mock.

Keyboard

KeyAction
Tab (first press)Focuses and reveals the skip link.
EnterMoves focus to <main id="main" tabindex="-1">; the next Tab reaches the first control in the page.
Tab again without activatingMoves on to the wordmark; the skip link hides.

Focus

The shared 2px ring at 3px offset. The skip link is never hidden while focused (WCAG 2.4.11), because it is placed over, not under, the sticky header.

Contrast

Label on raised surface

Motion

It slides on top over --duration-fast; reduced motion removes the transition.

Content

  • "Skip to content" on every page. Not "Skip navigation" or "Jump to main".
  • Sentence case, no punctuation, no icon.
