Post and recommendation

A post is a member's feed entry; a recommendation is a quoted endorsement of a provider or product. Both are cards with an author line.

WCAG 2.2 AAStatus: stable.post.reco.reco__text.list__meta

Overview

Use article.card.post for feed and profile posts (L2-012) and article.reco.card for recommendations on provider and member pages (L2-026). .list__meta is the muted secondary line used in cards. .meta appears only in the mocks index page and is not a product component.

Anatomy

  1. Author lineName · topic · area, then the church tag.
  2. Titleh2 in --text-card-title.
  3. Body and linkPlain paragraphs and one link.
  4. ActionsLike (toggle) and comment count.

Sizes

One size; .reco__text sets the quote at --font-size-lg.

States

  • Default.
  • Liked: the Like button has aria-pressed="true".
  • Loading: skeleton card.
  • Empty feed: empty state, no cards.

Responsive behaviour

  • Full width in the feed column at every size.
  • The author line wraps; the church tag moves to the next line as a unit.

Theming

Card surface and tokens; quote and caption use default and muted text.

Accessibility

Each post is an <article> inside a labelled section ("Latest posts"). The author is the first line so it is read first. Like is a toggle button with aria-pressed.

Content

  • Author line: name · topic · area.
  • Recommendation quotes use curly quotes and name the provider or product.
  • Comment counts are links: "3 comments".
