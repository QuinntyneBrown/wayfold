Responsive

Mobile first, five breakpoints from L2-015, and grids that adapt by themselves.

Overview

Wayfold is mobile first: styles start at 360px and add min-width queries at five breakpoints. Every page works at 360, 576, 768, 992 and 1200px without horizontal scrolling (L2-015.1). Grids are content-driven, so most of the adapting happens without a breakpoint at all.

Breakpoints

TokenResolved valueDeclared (light)Use
--layout-breakpoint-sm36rem576px (L2-015). Dialogs centre with all four corners rounded; toasts dock bottom-right at 24rem; footer links go in a row.
--layout-breakpoint-md48rem768px (L2-015). Full primary nav replaces the Menu button (L2-015.4); avatar button appears; vehicle detail goes two-column; site menu becomes a side sheet; page margin and gutter 32px.
--layout-breakpoint-lg62rem992px (L2-015). 12 guide columns; h1 44px, display 64px; section gap 96px; vehicle grid shows three or more columns (L2-015.3).
--layout-breakpoint-xl75rem1200px (L2-015). Page margin 80px.
--layout-breakpoint-2xl90rem1440px. The container stops growing; extra width becomes margin.

Media queries cannot read custom properties, so components.css repeats these values literally, and only these values. "Below" queries use the value minus 0.01rem (max-width: 47.99rem).

Usage

  • Write the phone layout first and add min-width queries.
  • Prefer intrinsic grids (auto-fit, minmax) to new breakpoints.
  • Hide nothing a member needs: the Menu holds every link the header drops.

Accessibility

  • Reflow at 320 CSS px without horizontal scroll (1.4.10, L2-015.1).
  • Orientation is never locked (1.3.4).
  • Targets stay 44px on every breakpoint (2.5.8).
  • The collapsed nav is a button operable by keyboard and touch (L2-015.4).
