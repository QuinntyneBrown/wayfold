Layout

One centred container, margins that grow with the screen, and six page templates built from content-driven grids.

Overview

Every Wayfold page sits in one centred .container under the site header: full width up to 1440px, with side margins that grow from 16px on phones to 80px on desktops. Inside it, pages are built from a few templates and four layout primitives.

The primitives (.container, .container--narrow, .stack, .cluster, .section-gap) and the grids (.vehicle-grid, .garage-grid, .filters, .detail-layout) are documented with their code on Container and page layout.

Column grid

A guide grid of 4, 8 and 12 columns. It is a reference for alignment, not a class: Wayfold grids are content-driven (auto-fit tracks with a minimum card width) and line up with it at each class.

Usage

  • Put every page in .container; never set a page's own max width or side padding.
  • Grids size by a minimum card width, not a column count, so they never need a breakpoint of their own.
  • Keep reading width at 62ch, even in a wide card.
