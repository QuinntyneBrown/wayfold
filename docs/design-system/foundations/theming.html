Theming

Light by default, dark on request or by OS preference, and both at WCAG 2.2 AA. Themes swap semantic tokens; components never know which theme they are in.

Overview

Wayfold ships a light and a dark theme. Light is the default; dark follows the operating system unless a page forces light, and the docs toggle (or t) switches it here. Both themes meet WCAG 2.2 AA with the same pairs.

Three tiers

  1. Primitives (--palette-*, --font-*): raw values. Components never read them.
  2. Semantic (--color-*, --shadow-*, --space-* …): what components read. Themes override this tier only.
  3. Component (--btn-*, --field-*, --alert-*): declared in components.css, always aliasing tier 2.

What changes in dark

  • Canvas and surfaces go to stone-950; raised surfaces (dialogs, sheets, popovers) lift to stone-850 because shadows cannot show depth on black.
  • The primary action inverts to light ink with dark text.
  • The accent lightens to pepper-300 so focus and selection keep 3:1.
  • Status tints become deep (callaloo-950, sorrel-950) with light text.
  • Shadows switch to black at higher opacity.
  • Vehicle photos are unchanged.

Applying a theme

<html data-theme="dark">   <!-- force dark -->
<html data-theme="light">  <!-- force light, ignore the OS -->
<html>                     <!-- follow prefers-color-scheme -->

A [data-theme] region can sit inside a page of the other theme, as in the panels above. The dark values live in two identical blocks in tokens.css (the attribute and the media query); edit both, then run check_contrast.py.

Preference modes

PreferenceEffect
prefers-contrast: moreDefault borders become strong; muted text becomes default; subtle becomes muted.
forced-colors: activeFocus uses Highlight; edges use CanvasText; dialogs, sheets and toasts gain a 1px outline.
prefers-reduced-motion: reduceTransition durations collapse; see Motion.

Usage

  • Read semantic tokens only, and a component themes itself.
  • Never write a theme check in a component ([data-theme=dark] .vehicle-card).
  • Check every new pair in both themes.

Accessibility

  • Every pair in contrast-pairs.json passes in both themes (L2-016.4).
  • Theme never changes layout, size or wording.
  • The theme toggle is a real button with aria-pressed.
