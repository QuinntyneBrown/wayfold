Foundation

Color

Ink on white, one red accent that means selected, and status colour only where a member must read a state: price ratings, verification and alerts.

Overview

Wayfold is a white canvas with near-black ink. Vehicle photos, prices and kilometres carry the page; colour stays out of their way. There is one accent hue, a warm red, and it always means selected, current or focused. Status colours appear only where a member needs to read a state: a green "Good price" or "Verified" badge, an amber "Too many attempts" alert, a red "Check these fields" alert or "Delete vehicle" button.

The primary action is ink, not red: "Message seller" and "Create account" are solid near-black pills. Red on a button would read as "selected" or "danger", so it is never used for a call to action.

Palette

Five ramps of primitives. Components never use them directly; they read the semantic roles below, which point at ramp steps per theme.

Stone (neutral)

Pepper (accent red)

Callaloo (success green)

Mango (warning amber)

Sorrel (danger red)

Sorrel is deeper and cooler than pepper so an error never reads as "selected".

Semantic roles

Roles are named for the job, not the hue: bg fills, fg text and icons, border edges, and four status families with bg, fg, border, icon and solid each. Themes override this tier only.

Usage

  • Read roles, never ramps. A component that names --palette-* breaks in dark mode.
  • One ink primary per view. The rest are secondary or ghost buttons.
  • Red means selected or focused. Do not use the accent for decoration, prices or calls to action.
  • Status needs words. A badge or alert always says what it means; the tint only reinforces it.
  • Muted is the floor for content. --color-fg-subtle is for placeholders and optional markers.

Accessibility

  • Text and icons meet 4.5:1 and 3:1 in both themes (1.4.3, 1.4.11, L2-016.4); decorative edges (--color-border-default, status borders) are marked min 1 in the pairs file.
  • Colour is never the only cue (1.4.1): ratings, verification and errors are words; links are underlined.
  • prefers-contrast: more promotes default borders to strong and muted text to default; forced-colors hands focus and edges to system colours. See Theming.
